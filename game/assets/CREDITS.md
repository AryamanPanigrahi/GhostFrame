# Art credits and licences

Every file in this folder is original work made for GhostFrame. There are no
third-party assets in it yet.

| Files | Source | Licence |
|---|---|---|
| `fighter/`, `stage/`, `fx/`, `hud/`, `ui/` (all PNGs) | Generated by `scripts/art/gen_art.py` and `scripts/art/fighter.py` in this repo (procedural pixel art) | Original, same terms as the rest of this repository |
| `font/main.ttf` ("GhostFrame Pixel") | Generated by `scripts/art/gen_art.py` from the 5x7 glyphs in `scripts/art/pixfont.py` | Original, same terms as the rest of this repository |

The repository has no licence file yet, so "same terms" means: all rights
reserved by the authors until one is chosen.

## Adding or replacing a file

When a file here is replaced with art from somewhere else (another tool, an
artist, an asset pack), add a row: the file(s), where it came from (link or
author), and its licence. The browser build is public, so the licence must
allow redistribution inside a game. Keep the same path, size and frame layout
as the asset checklist, then rebuild: build.rs embeds whatever is in this
folder.
